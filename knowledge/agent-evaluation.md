# Agent Evaluation

Base for golden cases, regression, safety, token economy, handoffs and evidence quality. Evaluation must run without network.

## Rubric
Evaluate factual correctness, coverage, false positives, traceability, scope, mutation safety, handoff, tokens and uncertainty.

## Golden Case
Each case has objective, fixtures, facts, expected findings, unresolved, next step and policy version. Plausible output without evidence fails.
