# Criacao de Agents

Todo agent declara objetivo, especialidade, entradas, saidas, ferramentas, skills, evidencias, autonomia, criterios de parada e handoff. O loop observe, plan, dispatch, debate, verify, synthesize e decide tem orcamento de rodadas, mensagens e tokens.

Use coordenador, builders, revisores, verifier e documenter. Deduplicate, selecione contexto por relevancia, compacte historico e escale modelos apenas quando o gate justificar. Nunca remova evidencia ou validacao para economizar tokens.

Referencias: https://www.anthropic.com/research/building-effective-agents ; https://cdn.openai.com/business-guides-and-resources/a-practical-guide-to-building-agents.pdf
