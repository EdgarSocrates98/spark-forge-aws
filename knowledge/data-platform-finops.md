# Data Platform FinOps

Base for S3, Athena, Glue, EMR, DynamoDB, Redshift and agent cost. Every number without billing data is an estimate with assumptions.

## Dimensions
Analyze cost by workload, environment, owner, dataset, bytes, requests, duration, workers, retries, storage, transfer and tokens.

## Gate
Require baseline, period, currency, region, price, volume, uncertainty and later measurement. Never invent percentage savings.
