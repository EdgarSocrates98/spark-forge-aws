# Lake Governance

Base for Lake Formation, Glue Catalog, DataZone, LF-tags, cross-account and governance. Separate catalog, authorization, storage, ownership, classification and SLO.

## Rules
- A present schema does not prove permission.
- Record producer, owner, steward, classification and retention.
- An unresolved permission blocks affirmative conclusions.
