# `sparkforge-aws install`

Instala o SparkForge no projeto/workspace (--scope) ou no HOME (--scope user, delegado ao integrate). Escreve so arquivos gerenciados; --dry-run mostra o plano.

## Subcomandos

| Subcomando | O que faz |
|---|---|
| [`sparkforge-aws install doctor`](#sparkforge-aws-install-doctor) | Saude da instalacao no alvo. |

## `sparkforge-aws install doctor`

Saude da instalacao no alvo.

```bash
sparkforge-aws install doctor --help
```

### Opções

Este comando não recebe opções.

Nenhuma: este verbo existe só na CLI.
