# `sparkforge-aws update`

Atualiza o runtime instalado pelo bootstrap.

```bash
sparkforge-aws update --help
```

## Opções

| Opção | Obrigatória | Valor | Repetível | Padrão | O que faz |
|---|---|---|---|---|---|
| `--to` | não | texto |  |  | Versao pinned (nunca 'latest'). |
| `--repo` | não | texto |  |  | Checkout para instalar/atualizar. |
| `--dry-run` | não | liga/desliga |  |  |  |

## Tool MCP equivalente

Nenhuma: este verbo existe só na CLI.
