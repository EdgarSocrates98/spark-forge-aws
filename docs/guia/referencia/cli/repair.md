# `sparkforge-aws repair`

Regrava assets gerenciados que sumiram ou mudaram.

```bash
sparkforge-aws repair --help
```

## Opções

| Opção | Obrigatória | Valor | Repetível | Padrão | O que faz |
|---|---|---|---|---|---|
| `--scope` | não | `project`, `workspace`, `user` |  | `project` |  |
| `--root` | não | texto |  |  |  |
| `--dry-run` | não | liga/desliga |  |  |  |
