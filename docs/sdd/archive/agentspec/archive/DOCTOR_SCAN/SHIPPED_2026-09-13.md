## Summary

O §22 de `prompt_new_evo.md` pedia que o produto escondido na CLI aparecesse: `doctor`, `scan .`, SARIF, GitHub Check, bot de PR e TUI. O entregue e o recorte que roda sem rede e sem dependencia nova. `sparkforge scan` (tool `sparkforge_scan`) monta um plano puro -- artefato coletado pelo `kind` do manifesto, com sha256 conferido, e codigo pela extensao --, roda um analyze por arquivo, `fuse` e `judge` sobre a uniao, grava em `.sparkforge/scan/` e, com `--format sarif`, gera o mesmo SARIF do `report github`. `sparkforge doctor` (tool `sparkforge_doctor`) faz nove checagens com status e o comando que resolve. TUI, bot de PR e Check com totais ficaram adiados. PR #63.

## Lessons Learned

### Process

- A doc para leigo (PR #62), escrita no meio desta frente, mediu as lacunas que o scan toca e mostrou que o `fuse` e parte do fluxo correto; o design mediu isso em 6 casos antes de decidir.
- O PR #62 so acrescentou `.py` de script e teste e mesmo assim moveu duas claims (corpus de `.py`), deixando a `main` vermelha; este PR carregou a correcao. Rodar o gate de lastro antes de abrir PR vale tambem para PR de docs.

### Technical

- Bytes presos por sha256 cru nao sobrevivem ao checkout do runner Windows (`core.autocrlf=true`); o recibo escapava porque normaliza a quebra de linha. `.gitattributes` com `-text` resolve na origem.
- Tool que chama a porta de outra tool herda o efeito dela: `code_status` grava a conferencia de frescor no indice, entao o doctor so confere a existencia do indice para continuar `_READ_ONLY` de verdade (teste mede o `mtime_ns`).
- Extrator tolerante e extrator que levanta sao dois comportamentos: Iceberg, Athena e EMR devolvem `*.unresolved` para dump malformado; CloudWatch, parquet-footer, IAM, grants e resource link levantam. `analyze_falhou` so aparece nos segundos.
- `pack_list.env` e o NOME da variavel, sempre presente; ler o campo sem medir deu um `ok` falso.

### Communication

- O recorte do §22 foi decidido por pergunta (doctor + scan) e o que ficou fora esta nomeado no BRAINSTORM, com a razao.

### Tools & Libraries

- O `.claude/agents/README.md` nao rastreado e orfao para o gate de espelho e derruba o lote a-c local; a suite roda com ele fora da arvore.
- Execucao da suite morta por memoria: relancar so os lotes restantes com `run_some_batches.py`.
