## Lessons Learned

### Process

- Register new files with Git intent-to-add before running repository gates that
  inspect the index; otherwise the version-tree gate reports false omissions.
- Keep test temporary directories outside the repository when path-security tests
  enforce workspace confinement.

### Technical

- Splitting one paired replay report preserves identical inputs and avoids duplicate
  execution while keeping the existing comparison report shape.
- `os.scandir` satisfies the repository's source scan policy for receipt discovery;
  `Path.glob` was rejected by the facts scan despite equivalent runtime behavior.

### Communication

- The build report's explicit acceptance mapping made ship readiness reviewable
  without reopening the implementation history.
- Recording the `.claude/sdd` versus `docs/sdd` checker boundary prevents a future
  operator from mistaking an indexing mismatch for an implementation failure.

### Tools & Libraries

- The AgentSpec linter provided a fast contract check for the design artifact.
- Ruff, pytest batch gates, and the repository scan tests caught different classes
  of defects and were all needed before archival.
