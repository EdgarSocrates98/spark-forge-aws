# Quickstart — Spark Forge AWS (EN)

Three commands:

```bash
git clone <spark-forge-aws>
cd spark-forge-aws
./setup.sh        # Windows: .\setup.ps1
```

Then, from any project:

```bash
sparkforge-aws analyze pyspark --path <arquivo-ou-dir>
```
